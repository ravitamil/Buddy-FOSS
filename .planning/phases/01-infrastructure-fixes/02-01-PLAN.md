### Task 4: Remove Console Statements (CRITICAL)

**Scope:** 180+ files
**Strategy:** Batched search and replace using bash script

**Script:**

```bash
#!/bin/bash

# Remove console.log/warn/error/debug statements
find src -type f \( -name "*.ts" -o -name "*.tsx" \) -exec grep -l "console\\.log\|console\\.warn\|console\\.error\|console\\.debug" {} \; | \
while read file; do
  if [[ "$file" == "src/services/EnhancedLoggerService.ts" ]]; then
    echo "SKIPPING EnhancedLoggerService.ts (legitimate debug output)"
  else
    echo "Removing console statements from $file"
    sed -i '/console\.log\|console\.warn\|console\.error\|console\.debug/d' "$file"
done

echo "Console statement removal complete"
```
