  <action>
For each of the 8 files that import from 'react-native-chart-kit', migrate to 'react-native-gifted-charts'.

**Migration pattern per file:**

1. Replace import:
   - `import { LineChart, BarChart, PieChart } from 'react-native-chart-kit'`
   - becomes `import { LineChart, BarChart, PieChart } from 'react-native-gifted-charts'`

2. Convert chart-kit data format to gifted-charts format:
   - chart-kit LineChart: `data={{ labels: [...], datasets: [{ data: [...] }] }}` becomes `data={[{ value: number, label: string }, ...]}`
   - chart-kit PieChart: `data={[{ name: string, amount: number, color: string }]}` with `accessor="amount"` becomes `data={[{ value: number, color: string, label: string }, ...]}`
   - chart-kit BarChart: `data={{ labels: [...], datasets: [{ data: [...] }] }}` becomes `data={[{ value: number, label: string }, ...]}`

3. Map chart-kit props to gifted-charts props:
   - `bezier` -> `curved`
   - `withDots={false}` -> `hideDataPoints`
   - `withVerticalLabels={false}` -> `hideYAxisText`
   - `withHorizontalLabels={false}` -> `hideXAxisText`
   - `fromZero` -> `startFromZero`
   - `filled` -> `areaChart` (add `startFillColor`/`endFillColor` for gradient)
   - `chartConfig={{ backgroundGradientFrom, backgroundGradientTo, color: (opacity) => ... }}` -> direct `color`, `startFillColor`, `endFillColor` props on the chart component
   - `width` and `height` props stay the same
   - `style` prop is not needed -- remove it

4. For colors that were derived from chart-kit's callback pattern `(opacity = 1) => \`rgba(X, Y, Z, \${opacity})\``: extract the base RGB values and use them directly as `color`prop strings (e.g.,`#4ECDC4`).

5. Use the existing gifted-charts wrapper components in `src/components/charts/` as reference for the correct prop patterns. They demonstrate PieChart donut, LineChart area, BarChart with colors.

6. Remove `chartConfig` objects entirely -- gifted-charts uses direct props instead of a config callback.

**Important considerations:**

- Keep the existing layout/positioning of charts in the screen (same parent View/YStack/ScrollView)
- Gifted-charts PieChart renders text automatically when `showText` is set. If chart-kit version showed percentages, add `showText` and `textColor` props
- Gifted-charts LineChart needs explicit `noOfSections` for Y-axis divisions (default is reasonable)
- Use `useTamaguiTheme()` to get theme-aware colors for chart elements (dark/light mode support per CLAUDE.md rules)

**Per-file specifics:**

- **BudgetAnalytics.tsx**: Has LineChart (daily trend), PieChart (category split), BarChart (comparison). Convert all three. The `chartConfig` object at line ~274 should be removed entirely.

- **BudgetDetailsScreen.tsx**: Has PieChart for budget category breakdown.

- **HomeScreen.tamagui.tsx**: Has LineChart for spending trend overview.

- **NetWorthScreen.tsx**: Has LineChart (net worth over time) and PieChart (asset allocation).

- **PortfolioAnalyticsScreen.tsx**: Has PieChart, LineChart, BarChart for portfolio analytics.

- **TransactionsScreen.tsx**: Has PieChart for expense categories.

- **PortfolioCategoryDetailScreen.tsx**: Has PieChart for category breakdown.
