## Execution Plan

### Task 1: Migrate BudgetContext

**Files:** `src/context/BudgetContext.tsx`

**Current approach:**

- Uses direct Supabase database calls (getBudget, saveBudget, deleteBudget)
- Mutations use simple state + direct service calls

**Migration target:**

- Replace `saveBudget/deleteBudget` with `queryClient.setQueryData()`
- Add `useMutation` hooks with `onMutate` / `onSuccess` for optimistic updates
- Use query keys: `queryKeys.budgets.list(uid)`, `queryKeys.budgets.active(uid)`

**Key patterns to apply:**

```typescript
// Add budget mutation
const addBudgetMutation = useMutation({
  mutationFn: async (budget: Omit<Budget, 'id'>) => {
    const newBudget = {...budget, id: createBudgetId()};
    await SupabaseDatabaseService.saveBudget(user.uid, newBudget);
    return newBudget;
  },
  onMutate: (variables) => {
    // Optimistic update
    queryClient.setQueryData(queryKeys.budgets.list(user?.uid ?? ''), (old: Budget[]) => [
      ...old,
      {...variables},
    ]);
    return {previous: old};
  },
  onSuccess: (newBudget) => {
    // Invalidate to refresh
    queryClient.invalidateQueries({queryKey: queryKeys.budgets.all});
  },
});
```

### Task 2-12: Migrate Remaining Contexts (Batch Strategy)

**Files:** All remaining context files

**Migration Pattern for All:**

1. Replace Supabase direct calls with `queryClient.setQueryData()` / `invalidateQueries()`
2. Add `useQuery` with query keys
3. Add `useMutation` with optimistic updates
4. Replace state with `queryClient.getQueryData()`
5. Use context-specific query key families

**Success Criteria:**

- [ ] All contexts use `queryKeys` from centralized factory
- [ ] All mutations use `useMutation` with optimistic updates
- [ ] State derived from `useQuery` where appropriate
- [ ] TypeScript compiles
- [ ] Lint passes
