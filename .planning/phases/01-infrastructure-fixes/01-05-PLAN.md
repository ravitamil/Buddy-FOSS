Create `src/services/OfflineMutationQueue.ts` -- a minimal offline mutation persistence layer.

**Design:**

- Uses MMKV (via react-native-mmkv-storage) to persist an array of pending mutation descriptors
- Each descriptor has: `{ id: string, mutationKey: string[], variables: unknown, meta: unknown, createdAt: number }`
- On app startup, after TanStack Query hydration, the queue replays persisted mutations via `queryClient.resumePausedMutations()` (TanStack Query handles the actual mutation execution -- the queue just ensures mutations survive app restart)
- Uses NetInfo to detect when connectivity returns and triggers replay

**Implementation:**

```typescript
import {MMKVLoader} from 'react-native-mmkv-storage';
import NetInfo from '@react-native-community/netinfo';

const QUEUE_KEY = 'offline_mutation_queue';

export class OfflineMutationQueue {
  private storage;
  private netInfoUnsubscribe: (() => void) | null = null;

  constructor() {
    this.storage = new MMKVLoader().withInstanceID('offline-mutations').initialize();
  }

  // Add a mutation to the offline queue
  async enqueue(descriptor: {
    mutationKey: readonly unknown[];
    variables: unknown;
    meta?: Record<string, unknown>;
  }): Promise<void> {
    const queue = (this.storage.getArray(QUEUE_KEY) || []) as any[];
    queue.push({
      id: Date.now().toString(36) + Math.random().toString(36).substring(2),
      mutationKey: descriptor.mutationKey,
      variables: descriptor.variables,
      meta: descriptor.meta,
      createdAt: Date.now(),
    });
    this.storage.setArray(QUEUE_KEY, queue);
  }

  // Remove a completed mutation from the queue
  async dequeue(id: string): Promise<void> {
    const queue = (this.storage.getArray(QUEUE_KEY) || []) as any[];
    this.storage.setArray(
      QUEUE_KEY,
      queue.filter((item) => item.id !== id),
    );
  }

  // Get all pending mutations
  async getPending(): Promise<any[]> {
    return (this.storage.getArray(QUEUE_KEY) || []) as any[];
  }

  // Clear the queue
  async clear(): Promise<void> {
    this.storage.removeItem(QUEUE_KEY);
  }

  // Listen for connectivity and replay mutations
  // Returns cleanup function
  listenAndReplay(replayFn: () => Promise<void>): () => void {
    this.netInfoUnsubscribe = NetInfo.addEventListener(async (state) => {
      if (state.isConnected) {
        await replayFn();
      }
    });
    return () => {
      this.netInfoUnsubscribe?.();
    };
  }
}

export const offlineMutationQueue = new OfflineMutationQueue();
```

Replace AsyncStorage with MMKV in the 4 domain data services. These services store domain data (loans, credit cards, subscriptions, budget data) that should use MMKV for consistency.

**For each service, follow this pattern:**

1. Remove `import AsyncStorage from '@react-native-async-storage/async-storage'`
2. Add `import { MMKVLoader } from 'react-native-mmkv-storage'`
3. Create a module-level MMKV instance:
   ```typescript
   const storage = new MMKVLoader().withInstanceID('service-name-storage').initialize();
   ```
4. Replace each `AsyncStorage.setItem(key, value)` with `storage.setString(key, value)` or `storage.setMap(key, JSON.parse(value))` as appropriate
5. Replace each `AsyncStorage.getItem(key)` with `storage.getString(key)` or `storage.getMap(key)` as appropriate
6. Replace any `AsyncStorage.removeItem(key)` with `storage.removeItem(key)`

**Key differences to handle:**

- AsyncStorage is async (returns Promise). MMKV is synchronous. Change `await AsyncStorage.getItem(...)` to just `storage.getMap(...)` or `storage.getString(...)`.
- AsyncStorage stores strings only (requires JSON.stringify/parse). MMKV supports `setMap`/`getMap` for objects directly, and `setString`/`getString` for strings.
- If the service has `await AsyncStorage.setItem(key, JSON.stringify(data))`, replace with `storage.setMap(key, data)` (no JSON.stringify needed).
- If the service has `JSON.parse(await AsyncStorage.getItem(key))`, replace with `storage.getMap(key)` (returns the object directly, or null).

**Service-specific notes:**

- **LoanStorageService.ts**: Stores loan objects in a single key. Replace `JSON.parse/JSON.stringify` + AsyncStorage with `storage.setMap/getMap`.

- **CreditCardStorageService.ts**: Stores credit cards and subscriptions under separate keys. Same pattern.

- **SubscriptionService.ts**: Stores subscription data. Replace similarly.

- **SmartBudgetService.ts**: Stores budget-related data. Replace similarly.
