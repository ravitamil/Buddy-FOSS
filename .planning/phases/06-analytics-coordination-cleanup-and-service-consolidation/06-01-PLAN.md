<objective>
Convert FinancialAnalyticsContext from a React Context provider that maintains its own state into derived hooks that compute synchronously over existing TanStack Query caches, then delete the provider.

Purpose: Eliminates an entire provider level from the tree. Analytics currently duplicates state that already lives in the transaction, category, and budget query caches. By deriving instead of duplicating, we remove the FinancialAnalyticsProvider, its loading state, and its re-render cascade.
Output: `src/features/analytics/` directory with derived hooks, deleted `FinancialAnalyticsContext.tsx` provider, updated consumers.
</objective>
