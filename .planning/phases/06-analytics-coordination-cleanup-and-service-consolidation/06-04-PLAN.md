  <action>
    For each of the 5 domains (transactions, groups, categories, budgets, wallets), create the feature module directory and files. Follow this exact pattern for each domain:

    **types.ts**: Re-export types from `@/types` and `@/types/*.types` relevant to the domain. This gives the feature module a single source of truth for its types.
    ```typescript
    export type { Transaction } from '@/types';
    // ... other domain types
    ```

    **service.ts**: Import from the domain database service created in 06-03 and re-export it. This is the adapter layer -- currently a thin wrapper, but the place where Zod validation (Phase 3) and business logic will live.
    ```typescript
    import { transactionDatabaseService } from '@/services/TransactionDatabaseService';
    export const transactionService = transactionDatabaseService;
    ```

    **queries.ts**: Import `useQuery` from `@tanstack/react-query`, `queryKeys` from `@/lib/query-keys`, and the service. Create query hooks matching the domain's read operations. Follow the pattern already established in the codebase contexts (e.g., `BudgetContext.query.tsx`, `LoanContext.query.tsx`).
    ```typescript
    import { useQuery } from '@tanstack/react-query';
    import { queryKeys } from '@/lib/query-keys';
    import { transactionService } from './service';

    export function useTransactions(userId: string) {
      return useQuery({
        queryKey: queryKeys.transactions.list(userId),
        queryFn: () => transactionService.getAll(userId),
        enabled: !!userId,
      });
    }
    ```
    Note: Map the `getGroups`/`saveGroups` naming from the database service to cleaner names (`getAll`, `create`, `update`, `delete`) in the feature service if appropriate. The feature service is the public API; the database service is the implementation.

    **mutations.ts**: Import `useMutation`, `useQueryClient` from TanStack Query. Create mutation hooks with optimistic updates and cross-entity invalidation. Follow the existing mutation patterns in the codebase contexts.
    ```typescript
    export function useCreateTransaction(userId: string) {
      const queryClient = useQueryClient();
      return useMutation({
        mutationFn: (data: Omit<Transaction, 'id'>) => transactionService.create(userId, data),
        onSuccess: () => {
          queryClient.invalidateQueries({ queryKey: queryKeys.transactions.all });
          queryClient.invalidateQueries({ queryKey: queryKeys.budgets.all });
        },
      });
    }
    ```

    **index.ts**: Barrel export all queries, mutations, types, and the service.
    ```typescript
    export * from './queries';
    export * from './mutations';
    export * from './types';
    ```
